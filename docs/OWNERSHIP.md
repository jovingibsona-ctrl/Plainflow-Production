# Ownership Checklist

To remain the project owner, create and control:

- GitHub repository
- Domain registrar account
- Cloud hosting account
- PostgreSQL database account
- Google Cloud OAuth application
- Slack app
- AI provider account
- Secret manager
- Billing account
- Production email account

Use your own email for the owner/admin account. Give collaborators the minimum permissions needed.

Never share production passwords or API keys in chat, source code, screenshots or public repositories.
